Academic file submission & routing system

From manual sorting to automatic routing

n8n Google Drive Google Sheets Gmail Tally Forms

The problem

Students submit coursework files through a form. Sorting and filing each submission into the right course folder and tracking sheet was done by hand — slow, and easy to get wrong at scale.

The fix

An n8n workflow reads each submission, routes it by course and section, validates it, then automatically uploads the file to the correct Google Drive folder and logs it in the matching Google Sheet. Anything invalid is logged separately and the student gets an automatic email asking them to resubmit — no manual sorting required.

Result

One workflow now handles routing and filing across 8 course sections, each with its own validation, upload, logging, and error-notification path.

CRM automation

Form submissions, qualified and routed by AI

n8n Google Gemini HubSpot Gmail

The problem

New leads came in through a form, but someone still had to read each submission, decide if it was worth pursuing, create or update the contact in HubSpot, and send a follow-up — the kind of task that gets slower and more inconsistent as volume grows.

The fix

An n8n workflow triggers on form submission and runs it through an LLM chain (Google Gemini) with a structured output parser, so the model returns clean, predictable fields instead of raw text. An If node checks that output — qualified leads get automatically upserted into HubSpot as a contact and receive a follow-up message through Gmail, with no manual review needed to reach that point.

Result

Every form submission is read, classified, and acted on the same way — CRM records stay current and the first follow-up goes out automatically instead of waiting on someone to get to it.
